Helyi magyar hangoskönyv-készítő: jegyzetből vagy kész forgatókönyvből neurális hangon felolvasott MP3 / M4B készül, az olvasónézetben a felolvasott rész kiemelve követhető.

Rétegek

  • Előkészítés: importálás (PDF, DOCX, EPUB, Markdown), képletolvasó, magyar normalizáló, kiejtési szótár
  • Hangmotorok: F5-TTS (magyar finomhangolás), Piper külön workerekben (JSON-RPC, saját venv)
  • Feldolgozás: feladatsor, gyorsítótár, whisper-alapú minőségellenőrzés, ffmpeg export
  • Felület: asztali ablak (pywebview, WebView2), szerkesztő, olvasónézet, MCP szerver

Technológia

Python · pywebview · FastAPI · Jinja2 · htmx · vanilla JS / CSS · SQLite · PyTorch · faster-whisper · ffmpeg · KaTeX
